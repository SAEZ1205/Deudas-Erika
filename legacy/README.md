# Código conservado como referencia

Esta carpeta evita que la implementación anterior interfiera con la aplicación Vite actual.

- `next-prototype/`: entrada y rutas antiguas de Next.js.
- `sites-runtime/`: configuración anterior de Vinext, Worker, Drizzle y pruebas de despliegue.
- `integrations/`: utilidades antiguas para Gemini y Twilio.
- `generated/`: PDF y capturas generadas durante versiones anteriores.

Ninguno de estos archivos participa en `npm run dev` ni en `npm run build`. El equipo puede eliminarlos más adelante después de revisar que no necesita recuperar ninguna pieza.
