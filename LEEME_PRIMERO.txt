MI MOVISTAR - RETO 1
====================

1. Instala Node.js 22.13 o superior.
2. Abre una terminal dentro de esta carpeta.
3. Ejecuta:

   npm install
   npm run dev

4. Abre http://localhost:3000

FLUJO DE DEMO:
Inicio -> Recibo -> Entiende tu recibo con LucIA.

La app oficial usa React + TypeScript + Vite + Tailwind.
El código anterior está guardado en legacy/ y no afecta la compilación.

Para verificar todo:

   npm run build

Lee README.md para la arquitectura y el reparto de las cuatro personas.
